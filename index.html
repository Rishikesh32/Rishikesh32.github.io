AI systems, architected for the agentic era

From voice agents and video dubbing to document AI and quant research: each system is designed with agent orchestration, MCP tools and eval-driven guardrails.

Flagship · Multi-agent · Finance pattern: hierarchical supervisor

AlphaDesk: multi-agent quant research platform

A supervisor agent breaks a research question into tasks and hands them to specialists. A market-data agent pulls prices and fundamentals through MCP servers. A research agent runs GraphRAG over filings and news. A quant agent writes and runs forecasting and backtest code in a sandbox. A risk agent checks exposure before anything reaches a human.

  • LangGraph supervisor with checkpointed state, so long research runs can pause and resume
  • Model routing: frontier models plan, small open-weight models extract and summarise
  • Every run traced in Langfuse and scored by an eval suite before a release ships
  • Human approval required before any signal leaves the system

Voice AI · Real-timelisten → reason → act → speak

EchoAgent: real-time voice agent

A voice agent that holds natural phone and web conversations. Streaming speech-to-text feeds an LLM agent that calls tools to look up, book and update records, and streaming text-to-speech replies with low latency. It copes with interruptions mid-sentence and hands off to a person when asked.

Speech · Videomulti-stage media pipeline

DubFlow: AI video dubbing pipeline

Takes a video in one language and returns it dubbed in another. Whisper transcribes with timestamps, speaker diarization separates the voices, an LLM translates while keeping context and timing, and text-to-speech generates a voice for each speaker that is aligned to the original timing and mixed back with the background audio.

ListingStudio: multimodal listing generator

It goes beyond tagging photos. Vision models classify every image by room and feature, then LLM agents generate the rest of each listing at scale: the view and surroundings, amenities, neighbourhood details and the full description. A critic agent checks every claim against the photos and listing data, and screens out non-compliant language before anything is published.

Recommendations · OTTcluster → rank → serve

CineMind: OTT recommendation engine

The recommendation backend for an OTT platform. Viewers are grouped into taste clusters from their watch history, so people with similar habits are shown similar films, and a conversational agent on top explains each pick in plain language.

  • Watch events become user embeddings, clustered into taste groups that refresh on a schedule
  • Candidates come from the viewer's cluster plus item similarity, then a ranker personalises the list
  • Redis serves precomputed recommendations, sessions and trending lists for fast reads
  • FastAPI microservices on PostgreSQL, packaged with Docker
